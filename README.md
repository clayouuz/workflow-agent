# workflow-agent

workflow-agent 是一个帮助编码 Agent 管理复杂任务的工作流项目。

它为任务保存可恢复的上下文、讨论结果、实施进度和验证证据，让 Agent 能够在多步骤、多会话任务中保持目标一致、过程可追踪、结果可验收。

LLM 负责理解任务、判断复杂度和做语义决策；workflow-agent 负责保存上下文、管理状态、装配引用和检查验证结果。

## 快速开始

面向用户的推荐方式是先让 LLM 注册一个使用 workflow-agent 的 Skill。

将本项目目录下的 [SKILL.md](SKILL.md) 作为模板交给 LLM，并说明：

```text
请以这个 SKILL.md 为模板，注册一个使用 workflow-agent 的 Skill。
它需要在复杂任务中管理任务台账、讨论状态、验收方式和验证证据，
并在简单任务中保持轻量处理。
```

注册完成后，在目标项目中调用这个 Skill 即可开始使用 workflow-agent。需要直接运行 CLI 或查看完整参数时，再参考 [docs/cli-commands.md](docs/cli-commands.md)。

## 功能概览

### 任务台账

为每个任务保存目标、范围、当前阶段、下一步和相关资料，支持任务创建、绑定、恢复和跨会话继续工作。

### 讨论状态

对于多步骤或高影响任务，LLM 可以启用讨论状态机，明确三项内容：

- 目标；
- 具体方案；
- 验收方式。

讨论结果和用户确认会被保存，设计发生变化时可以识别旧确认失效。

### 实施与验收

Benchmark 描述什么结果算完成，Work Item 描述需要执行的工作。两者分别管理实施进度、阻塞、恢复和最终验收。

### 上下文管理

系统根据当前任务装配必要的上下文，支持精确加载文档章节。讨论状态、设计文档和当前 Benchmark 可以进入恢复入口，历史和原始材料默认保持在冷层。

### 验证与证据

支持自动测试、影响测试、人工验收、验证状态和内容指纹检查。验证结果区分通过、失败、过期和不完整，避免把未执行的检查误报为已通过。

### Operation Log

按任务保存重要的用户决策和 Agent 检查点，使用 `user` 或 `ai` 区分来源，便于后续恢复和复盘。

### 知识与启发

- Knowledge：保存跨任务都适用的路径、入口和约定；
- Heuristics：保存非强制的工作启发和经验记录。

### 工具扩展

登记已有工具的能力边界，提出新工具或已有工具的扩展申请。工具提议本身不代表已经安装、注册或可用。

### 领域 Pack

Pack 用于目标、方案和验收方式的讨论。Agent 根据当前讨论判断相关性，通过 `ledger pack list/enable/disable` 按任务管理领域材料，显式读取所需指南或模板，将结论写入任务设计供用户确认。实施阶段依据已确认设计，约束变化时再回到讨论。

Pack 只作用于当前任务，不会自动扩散到其他任务；启用只安装文件，不代表内容已读取或讨论已完成。具体流程见工作区的 `discussion/workflow.md#讨论中的领域扩展包`。

- `cocos`：Cocos Creator 场景、Prefab、组件与资源设计模板；
- `game-architecture`：在游戏架构讨论阶段，从玩家体验和表现压力出发比较候选架构，明确状态所有权、表现契约、生命周期、模块边界和代表性端到端纵切，形成待用户确认的最终架构。

两个 Pack 可以按任务组合启用。`game-architecture` 不补全玩法设计，也不接管 Benchmark、实施进度或 Git 等流程管理。

### 迁移与恢复

工作区包含结构版本和模板指纹。升级时会保留用户自定义内容，必要时生成候选文件，并为废弃文件提供可恢复归档。

### 路径可移植性

用户配置支持相对路径、绝对路径和 `~/workflow-agent` 形式，减少对特定用户目录的依赖。

## 工作方式

```text
识别或建立任务
  → 加载当前上下文
  → 简单任务直接处理，复杂任务先完成讨论
  → 执行实施工作
  → 自动或人工验证
  → 验收并保存结果
  → 需要时恢复、复盘或迁移
```

复杂任务的讨论状态是流程记录，不替代用户对目标、风险或主观结果的判断。用户需要亲自观察的界面、设备或体验，仍需由用户验收。

## 工作区组织

```text
.workflow/
├─ discussion/       工作流、上下文和操作记录规则
├─ knowledge/        跨任务知识
├─ heuristics/       启发策略和学习记录
├─ tools/            工具能力卡片和工具扩展记录
├─ tests/            测试配置和调用图缓存
└─ tasks/<任务>/ledger/
   ├─ authority.md   任务目标和约束
   ├─ current.md     当前恢复入口
   ├─ designs/       讨论和设计文档
   ├─ benchmarks/    验收契约
   ├─ work-items/    实施工作
   ├─ state/         机器状态
   ├─ verification/ 验证证据
   ├─ operations/    过程日志
   └─ snapshots/     已编译结论
```
