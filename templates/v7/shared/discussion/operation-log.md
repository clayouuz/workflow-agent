# 操作记录规则

LLM 在出现有复盘价值的语义检查点时主动执行 `log append`。

应记录：
- 用户确认改变目标、范围、方案、代码设计或验收方式；
- 一组有意义的项目修改完成、失败或被撤回；
- 测试、运行观察或人工反馈改变了原有判断；
- 确认根因、阻塞条件、恢复条件或风险；
- 旧结论、方案或证据被新结论取代；
- 完成一个值得独立复盘的工作检查点。

不记录：
- 普通只读查询和无决策价值的重复命令；
- 每个文件的机械编辑过程或完整终端输出；
- 已由 Artifact 保存的大段内容；
- 密钥、令牌和敏感环境信息。

同一推理或实施检查点尽量合并为一条记录。日志只写摘要、原因和 Artifact 引用，不复制大文件内容。
