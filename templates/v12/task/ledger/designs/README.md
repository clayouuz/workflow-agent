# 设计文档

- 通用任务默认使用 `template-general.md`。
- 讨论阶段按 `discussion/workflow.md#讨论中的领域扩展包` 选择并读取 Pack。
- 讨论游戏架构时可启用 `game-architecture`，读取 `game-architecture-guide.md`，参考 `template-game-architecture.md` 记录候选比较和架构决策。
- 讨论 Cocos 场景、Prefab、组件的修改方案及验收方式时可启用 `cocos`，读取并参考 `template-cocos-scene.md`。两包可按讨论需要组合使用。
- pack 是任务级可选内容；未启用时不生成 Cocos 模板，也不应把它加入当前上下文。
- 将结论写入独立的任务设计，保留包原件；使用讨论状态机时补齐“目标”“具体方案”“验收方式”章节，并以该设计记录讨论、确认和恢复引用。实施依据已确认设计。
- 无关章节可以删除，不为填满模板增加内容。
