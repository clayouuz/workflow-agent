# 工具：ts-test-runner

## 能力边界
能做：
- 黑盒：自动发现配置的测试目录下 *.test.ts，运行 test_* 开头的用例，报告 pass/fail，失败时退出码非 0
- 白盒：构建函数调用图，对变更函数逆向找调用者，跑受影响测试（test impact）
- 测试配置：test config 写入源码目录/测试目录
- 测试文件内相对导入需写全 .ts 扩展名（Node ESM 规则）

不能做：
- 测试依赖 Cocos 引擎节点/组件/场景的内容
- 需要浏览器/渲染环境的测试

## 超出边界处理
- 标记 pending，并提示用户手动验收；或提交 tool request 扩展能力
