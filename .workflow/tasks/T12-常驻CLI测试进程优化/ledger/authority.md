# 权威说明

## 目标
复用测试夹具槽位中的 CLI Node 进程，减少每个用例重复启动 TypeScript CLI 的开销，同时保持工作区隔离和现有 CLI 集成覆盖。

## 范围
- CLI 可嵌入入口与测试专用 NDJSON worker。
- tests/helpers/cli.ts 的 worker 生命周期、请求响应和故障清理。
- worker 复用与 CLI 行为回归测试。

## 非目标
- 不改变生产 CLI 命令语义或输出内容。
- 不在本轮引入测试并行执行。

## 已确认要求
- 用户于 2026-08-29 确认常驻 CLI worker 优化方案。
