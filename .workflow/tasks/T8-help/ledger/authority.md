# 权威说明

## 目标
让 LLM 可按任务复杂度启用讨论状态机，明确记录目标、具体方案和验收方式，并在确认链完整时才允许执行。

## 范围
- 复杂任务的目标、方案、验收方式讨论与确认状态机。
- 非修改类复杂任务复用同一流程，简单任务保持旁路。
- v8→v9 模板迁移、CLI、Machine Event 和测试文档。

## 非目标
- 不让 CLI 判断任务复杂度。
- 不把语义质量判断硬编码为规则。

## 已确认要求
- 用户于 2026-08-29 确认三项讨论产出和由 LLM 判断复杂度的方案与代码设计。
