# 路径可移植化设计

## 目标
用户看到和配置的 workflow-agent 路径使用 `~/workflow-agent`，换机器或换用户目录后仍可运行。

## 具体方案
新增统一路径归一化工具：读取时展开 `~`，写测试配置时将用户目录下路径序列化为 `~` 形式、仓库内路径保留相对形式；文档和注册 Skill 使用 `~/workflow-agent`。调用图内部继续保存解析后的绝对路径。

## 验收方式
覆盖 `~`、`~\\`、相对路径和绝对路径读写；配置写入不出现当前用户绝对路径；全量测试、调用图构建和 verify-demo 通过；项目与 Skill 中不再残留用户目录硬编码。
